# Boring Lecture

By Makeye Buchanan
A webpage with the theme of 'Boring Lecture'.

#### Technologies Used

* HTML
* CSS

## Description

This webpage consists of a lecture about HTML from the view of an early student originally used to practice styling via classes in CSS.

## Setup/Installation

1. Click on the green 'code' button.
2. Download ZIP.
3. Enter your file explorer and look for the ZIP file 'Boring Lecture', which should be in your Downloads.
4. Right click on the file and click 'Extract All' then 'Extract'.
